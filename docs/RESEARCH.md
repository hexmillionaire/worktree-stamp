# Why this boundary — October 28, 2026

[Claude Code #104504](https://github.com/anthropics/claude-code/issues/104504) was opened October 23, 2026 and remained open when checked October 28. The reporter asks that later source edits invalidate earlier test claims, that pipeline exit status be preserved, and that narrowed runs be described accurately. Its statistics concern one team's sessions; they are not population estimates. A content checkpoint can address only the freshness part, so this project does not claim to detect false completion, validate test selection or repair shell status.

At revision [f865d82](https://github.com/mohamedzhioua/agent-done-or-not/blob/f865d82b3df8d28a64c4dd799bde23ea239e68c4/done-gate.sh#L88-L90), Agent Done Or Not records `HEAD^{tree}` and a dirty boolean. Its [drift comparison](https://github.com/mohamedzhioua/agent-done-or-not/blob/f865d82b3df8d28a64c4dd799bde23ea239e68c4/done-gate.sh#L176-L193) checks changed HEAD and clean-to-dirty transition. Two different dirty contents under one HEAD can therefore remain indistinguishable to that particular comparison. This is not a criticism of its broader command receipts, policies or CI reruns; those solve different problems.

Fingerprints are established prior art. [oh-my-hermes](https://github.com/rlaope/oh-my-hermes/blob/main/docs/WORKING-TREE-FINGERPRINT.md) already implements a careful final-working-tree fingerprint in a larger goal/evidence suite and deliberately treats unchanged final bytes as identical across staging changes. [Groundtruth](https://github.com/akahkhanna/groundtruth) includes stale-by-tree transcript sensors. Both repositories were unarchived when checked. [Backcheck](https://github.com/VectorInstitute/backcheck) audits transcripts and stale claims; it was archived when checked. Worktree Stamp is a smaller provider-neutral primitive whose identity also includes the index; it does not claim novelty or superiority.

The Git plumbing is intentionally narrow: [git-ls-files](https://git-scm.com/docs/git-ls-files) exposes staged mode/object/stage records and nonignored untracked paths with NUL delimiters. Two explicit cached raw-diff views detect unsupported intent-to-add semantics; external diff, textconv and rename detection are disabled. The collector hashes actual regular-file bytes instead of trusting `git status`, never applies content filters, strips inherited Git redirection, and disables optional index refresh locks, lazy object fetching and fsmonitor. Git's [linked worktree model](https://git-scm.com/docs/git-worktree) keeps per-worktree HEAD/index metadata separate; fixtures verify that the collector uses the selected checkout.

The [Git 2.45 manual](https://git-scm.com/docs/git/2.45.0#Documentation/git.txt---no-lazy-fetch) documents the explicit `--no-lazy-fetch` capability. Requiring that flag makes older Git reject the invocation rather than silently ignore a newer environment safeguard. Missing local objects remain indeterminate instead of being fetched.

Future integrations should combine independently observed facts without relabeling them. A command runner can keep its own exit status and attach a before/after content stamp, but the stamp does not establish what happened between reads or whether the command was meaningful. No source bytes, absolute roots, session transcript or remote URL need to be published to inspect this format; filenames and hashes can still be private.
